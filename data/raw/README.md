# Raw Data

This project uses the publicly available **Telco Customer Churn** sample dataset originally published as an IBM sample dataset.

Dataset characteristics:
- 7,043 customer records
- 21 columns
- Target: `Churn`
- Includes demographic, service, contract, billing, and tenure information

For reproducibility, download the CSV and place it here as:

`data/raw/WA_Fn-UseC_-Telco-Customer-Churn.csv`

Public dataset reference: IBM's customer churn sample project.

The raw CSV is intentionally not committed to this repository; the analysis notebook loads it from the local `data/raw/` directory.
